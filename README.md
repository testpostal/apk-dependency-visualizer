# Инструмент визуализации графа зависимостей (Вариант №16)

## 1. Общее описание
Данный проект разработан в рамках дисциплины «Конфигурационное управление» (РТУ МИРЭА). Приложение представляет собой CLI-инструмент для анализа и визуализации графа зависимостей пакетов Alpine Linux (формат `apk`). Программа написана на языке Java без использования сторонних менеджеров пакетов и внешних библиотек парсинга.

## 2. Описание функций и настроек
На Этапе 1 приложение считывает конфигурационный файл `config.yaml` в корне проекта, проверяет корректность параметров и выводит их в консоль.

Основные настройки в `config.yaml`:
* `package_name` — Имя анализируемого пакета (например, `curl`).
* `repository_url` — URL-адрес репозитория Alpine Linux.
* `repo_mode` — Режим работы с репозиторием (`online` или `offline`).
* `package_version` — Версия анализируемого пакета.
* `output_image_path` — Путь для сохранения сгенерированного графа в формате PNG.
* `ascii_tree_output` — Флаг вывода зависимостей в формате ASCII-дерева (`true`/`false`).

## 3. Описание команд для сборки и запуска тестов
Для автоматизации сборки, тестирования и запуска используется единый скрипт `run.bat`.

* **Запуск всего цикла (сборка, тесты, старт):**
  Выполните команду в терминале или дважды кликните по файлу в проводнике:
  ```bash
  run.bat
  ```

Внутри скрипта последовательно выполняются:
1. Компиляция исходного кода (`src/Main.java`) и тестов (`tests/Test.java`) в папку `out/`.
2. Запуск автоматических тестов обработки ошибок на поврежденных файлах конфигурации.
3. Запуск основного приложения с чтением корневого `config.yaml`.

## 4. Примеры использования
Пример успешного вывода параметров при запуске приложения:
```text
===Параметры конфигурации===
package_name: curl
repository_url: https://alpinelinux.org
repo_mode: online
package_version: 8.2.1-r0
output_image_path: output/graph.png
ascii_tree_output: true
```
