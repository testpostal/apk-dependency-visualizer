# Инструмент визуализации графа зависимостей пакетов Alpine Linux

## 1. Общее описание
CLI-утилита на языке Java для сбора, анализа и визуализации графа зависимостей пакетов Alpine Linux (формат `apk`). Загрузка индекса репозитория, распаковка архивов `.tar.gz` и разбор конфигурации YAML реализованы средствами стандартной библиотеки Java без использования внешних менеджеров пакетов и сторонних парсеров.

## 2. Описание функций и настроек
При запуске приложение считывает конфигурационный файл `config.yaml`, валидирует все параметры, загружает индекс пакетов `APKINDEX.tar.gz` из указанного репозитория Alpine Linux, извлекает файл `APKINDEX` и выводит прямые зависимости для заданного имени и версии пакета.

Основные параметры в `config.yaml`:
* `package_name` — имя анализируемого пакета (например, `2bwm`).
* `repository_url` — URL-адрес репозитория Alpine Linux или путь к файлу тестового репозитория.
* `repo_mode` — режим работы с тестовым репозиторием (`true` — локальный файл, `false` — удалённый репозиторий).
* `package_version` — версия анализируемого пакета (например, `0.4-r0`).
* `output_image_path` — путь для сохранения итогового изображения графа в формате `.png`.
* `ascii_tree_output` — режим вывода зависимостей в формате ASCII-дерева (`true`/`false`).

## 3. Сборка и запуск тестов
Для компиляции, прогона тестов и запуска основного приложения используется скрипт `run.bat`:

```bash
run.bat
```

Скрипт последовательно выполняет:
1. Компиляцию исходного кода из `src/*.java` и тестов из `tests/*.java` в директорию `out/`.
2. Запуск автоматических тестов валидации параметров конфигурации.
3. Запуск основного приложения с чтением файла `config.yaml`.

## 4. Примеры использования
Пример `config.yaml`:
```yaml
package_name: 2bwm
repository_url: https://alpinelinux.org
repo_mode: false
package_version: 0.4-r0
output_image_path: graph.png
ascii_tree_output: false
```

Пример вывода в консоль:
```text
Прямые зависимости для 2bwm (0.4-r0):
- so:libc.musl-x86_64.so.1
- so:libxcb-ewmh.so.2
- so:libxcb-icccm.so.4
- so:libxcb-keysyms.so.1
- so:libxcb-randr.so.0
- so:libxcb-xrm.so.0
- so:libxcb.so.1
```
